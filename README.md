# Clash 自动选择节点

## 直接运行

双击 `dist/ClashAutoSelector.exe`。程序包含中文 OCR 模型，无需安装 Python，识别不连接外部服务。

1. 打开 Clash Verge，切换到示例图中的深色“代理”页面，展开“节点选择”代理组。
2. 确保测速按钮和所有需要比较的节点同时出现在屏幕上，不要让其他窗口覆盖这些位置。
3. 打开本程序，点击“刷新”，选择 Clash 窗口。只有一个窗口时会自动选择。
4. 设置测速间隔、测速等待、节点关键词。默认分别为 **60 秒、10 秒、新加坡**。
5. 可先点“识别预览”检查卡片框、延迟文字和红圈测速按钮位置。预览会切换前台，但不点击测速或节点。
6. 点击“开始循环”。按“停止”或全局快捷键 **Ctrl+Alt+F12** 停止；停止后不会继续选择节点。OCR 正在运行时，需等本次识别返回才能完全退出。

运行时会自动把 Clash 切到前台，可能短暂打断其他操作。Windows 拒绝激活、窗口被遮挡或页面识别失败时，本轮跳过并显示原因。

## 测速和切换

- 启动立即测速，等待设定秒数后识别延迟，选取名称包含关键词且延迟最低的节点。英文关键词忽略大小写。
- `Timeout`、`Error`、`Check`、空白、低置信度结果不参与数值比较。当前已是最优节点时不重复点击。
- 多个节点延迟并列时，优先保留当前选择，否则选择画面中从上到下、从左到右的第一个。
- **全部匹配节点都明确为 Timeout：立刻重新点击测速，完整等待测速等待时间，再比较。连续全部超时就持续重试，可随时停止。**
- 无匹配节点、存在无法识别的卡片、混合 Error/Check/空白，不触发“全部超时”立即重试。
- 正常周期从最近一次点击测速开始计时。例如 0 秒测速、10 秒选节点、60 秒开始下一轮。执行超出周期时跳过错过的时间点，不补跑、不并发。
- “立即执行一轮”在停止状态下执行一次；若全部超时，仍会按上述规则连续重试。在循环中点击会安排当前轮结束后尽快执行下一轮。
- 修改后点击“保存设置”，下一轮生效。等待中的当前轮使用开始时的设置。时间允许 1～86400 秒，可输入小数。

## 适用范围

适配需求截图中的 Clash Verge 深色代理页面，支持窗口移动、拉伸、列数变化和常见 Windows 缩放。不会自动滚动、修改 Clash 配置、切换订阅或调用 Clash 控制接口。被隐藏的节点无法参与比较；更换主题、客户端界面发生较大变化或文字太小时，识别可能失败。

若识别不正常，先使用预览检查，适当放大窗口。若日志提示无法点击或激活，确认 Clash 与本程序的权限等级一致。关闭重叠窗口后再运行。快捷键被占用时程序会提示，此时使用“停止”按钮。

## 设置和日志

保存位置：`%LOCALAPPDATA%\ClashAutoSelector`。

- `config.json`：设置文件。
- `selector.log`：运行日志，单个最多约 2 MB，保留 3 个历史文件。

## 从源码运行或重新打包

需要 Windows 10/11、64 位 Python 3.13；安装依赖时需要网络。最终 EXE 日常运行不需要网络下载模型。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

在项目目录执行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`，会安装依赖、运行测试并生成 EXE。原始五张截图应保留，用于离线验收。

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_core test_runner test_windows
.\.venv\Scripts\python.exe verify_screenshots.py
```

`verification` 目录保存截图识别预览和 EXE 自检报告。EXE 支持 `--self-test 报告文件绝对路径`，该模式不点击桌面、禁止网络连接，并检查打包后的中文 OCR 模型和模板能否加载。
